Стабильное подключение / 3

1. Установка приложения

Для iPhone установите приложение Incy из App Store, затем откройте его и разрешите добавление VPN-конфигурации.

06 Скачать →

2. Добавление подписки

В Вашем буфере обмена уже сохранены подключения. Откройте Incy, нажмите «+» для добавления нового подключения и выберите «Импорт из буфера обмена». При необходимости Вы можете заново скопировать ссылки кнопкой «Инициализация» выше.
